# Request Capture Platform

Zero-dependency Node.js HTTP request capture server with full header fidelity.

## Quick Start

```bash
node server.js
```

Capture server: http://localhost:8080
View dashboard: http://localhost:8081

Test pages:
- /bare - minimal HTML
- - /full - comprehensive test with 33+ request types
 
  - ## Deploy to Render
 
  - Connect this repo on render.com as a Docker web service.
